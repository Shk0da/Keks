# KEKS: Охотник на Суккубов — офлайн-APK

Изометрический rogue-lite ARPG (18+, комедийная эротика с пиксельной
цензурой) — целиком в одном APK, **работает без интернета**, разрешений
в манифесте нет. Отдельное окно WebView, весь прогресс в `localStorage`
(переживает перезапуски и попадает в системные бэкапы).

Кекс — охотник в одном лишь плаще — спускается в бесконечные подземелья
за демонессами, реликвиями и лёгким смущением. Основное оружие —
Хлыст Праотца: древняя магия цензуры навсегда скрыла его истинный облик
пиксельной мозаикой. Все, кто разглядел, стесняются рассказывать.

## Возможности

- 🗡 **Бой в стиле Diablo**: удар хлыстом с комбо (третий удар — круговой),
  вихрь над головой, рывок с неуязвимостью, флирт-комплимент (смущает
  демонесс). Криты, хит-стоп, тряска экрана
- 🧪 **Шесть эликсиров** (лента внизу экрана, клавиши 1–6): «Стыд-трава»
  (лечение 45%), «Заячья Прыть» (+50% скорости, 12с), «Дух Праотца»
  (неуязвимость 4с), «Гнев Суккуба» (+50% урона, 15с), «Месть Кокетки»
  (+40% скорости атаки, 12с), «Слёзы Владычицы» (мана полная + вихрь
  без затрат маны 8с). Активные эффекты — с таймерами в HUD; доля боевых
  зелий в дропе растёт с глубиной, у Мадам Векс есть все виды
- ⚡ **Динамика боя**: «Азарт» — множитель опыта/золота до ×3 за цепочку
  фрагов без урона по себе (рвётся от удара); **элитки** с диабловскими
  аффиксами (Стремительная, Пылкая, Липкая, Кровожадная, Хрупкая ярость —
  аура, ★, ×2.2 HP, ×2.5 дроп); **пар-время** этажа с таймером в HUD и
  золотым бонусом за скоростную зачистку; случайные **«Вторжения»** —
  глубина высылает подмогу посреди этажа; **рывок бьёт насквозь** и
  замедляет — можно проходить строй, а не обходить
- 🚪 **Переходы этажей по-диабловски**: выход — готические врата спуска
  (арка с рунами и решёткой); при подходе решётка со скрежетом
  поднимается, шаг в проём — карточка затемнения «ГЛУБИНА N · Название
  темы» с репликой, и новый этаж раскрывается из тьмы
- 🧱 **Бесконечные данжи**: 3 планировщика (комнаты+коридоры, органические
  пещеры, крестовый собор) × 5 тем (Катакомбы, Инферно-будуар, Ледяные
  Чертоги, Шёлковый Улей, Библиотека Порока) — с лавой, инеем, паутиной,
  алтарями, коконами и сундуками
- 👹 **8 типов демонесс** с ИИ (поток-филд навигация): от импок до
  Мраморных Дам; летающие гарпии, плевуньи-ламии, тенетницы
- 👑 **5 боссов** каждые 5 глубин: Матрона Улья, Княгиня Инферно,
  Королева Стужи, Библиотекарь Лилит и Владычица Глубин — с паттернами,
  телеграфами удара, фазой ярости и свитой
- 📈 **Прокачка до 100 уровня** (максимум): кривая опыта откалибрована на
  **~1000 часов** оптимальной игры (1→2 за минуты, 50→51 ≈ 3.5 ч, 99→100 ≈ 57 ч;
  расчёт — `tools/calibrate-xp.mjs`). Дерево навыков: 4 ветви × 5 узлов,
  84 ранга на всё дерево — полностью закрывается к 100 уровню, капстоуны
  (5-е узлы) открываются с 40 уровня
- 🗡 **Оружейная «Точило Праотца»**: 10 хлыстов-оружия коллекцией — от «Верёвки
  Простака» до «Бича Владычицы Глубин» (★1–★5, у каждого свой множитель урона,
  скорости, длины и дуги, у половины — особенность: яд, огонь, замедление,
  крит, золото, вампиризм). **Заточка** до +15 (+8% урона оружия за уровень,
  цена растёт геометрически). **Гнёзда под камни**: 6 видов × 5 редкостей
  (от Осколка до Звёздного) — рубины (урон), алмазы (скорость атаки),
  аметисты (крит), топазы (золото), изумруды (похищение HP), сапфиры (дешевле
  вихрь); редкость растёт с глубиной. Оружие падает с боссов, сундуков и
  «Хлыста в мешке» торговки; дубликаты меняются на золото и камень
- 📉 **Чем выше уровень — тем сложнее**: здоровье и урон нечисти растут и от
  глубины, и от уровня героя (индикатор «угрозы» в HUD). А «усталость» режет
  опыт, если сидеть на глубине меньше 0.8×уровня — качаться на мелководье нельзя
- 💰 **Экономика**: золото, торговка Мадам Векс (зелья, перманентные апгрейды,
  «кот-в-мешке» с реликвией, безлимитные эндгейм-эликсиры +3%)
- 💰 **Экономика**: золото, торговка Мадам Векс (зелья, перманентные
  апгрейды, «кот-в-мешке» с реликвией)
- 💾 **Сохранение**: автосейв на каждый этаж/лагерь/смерть; смерть
  забирает 20% золота, но не прогресс
- 🎨 **Вся графика процедурная** (canvas): динамический свет факелов,
  туман войны с памятью карты, частицы, реплики над врагами. Пошлые штрихи:
  дрожь и румянец от ударов, сердечки-синяки, воздушные поцелуи флирта,
  обморок «лапки к небу» при смерти, сердечковый дождь над боссом, поза
  пития зелий с пузырьками
- 🔊 **Весь звук генеративный** (WebAudio, ни одного аудиофайла):
  мастер-шина с компрессором и **свёрточная реверберация подземелья**
  (импульс синтезируется: двухфазное затухание, стерео-ширина, пре-делей);
  удары многослойные — вуш → щелчок-транзиент → низкое «тело» → звон,
  с индивидуальной глубиной реверберации у каждого слоя. Музыка —
  аккордовые прогрессии по темам (пэд-детюн с «дышащим» фильтром,
  суб-бас, вибрато-мелодика с панорамой, пульс-кick в Инферно,
  шумовое «дыхание» данжа, далёкие стоны из глубин). Пошлый слой:
  стоны-глиссандо вслед хлысту, хихиканье, блаженные вздохи, чмоки, глотки
- 🕹 Управление: тач (виртуальный стик + кнопки) и клавиатура
  (WASD, J/K/Shift/C/Q, Esc)

## Сборка

Windows (git-bash; нужны `java`/`javac`/`keytool` — JDK 17+, `python`,
`node`, `unzip`, `openssl`):

```bash
./tools/build-apk.sh
```

SDK (build-tools 35 + platform 34) берётся из `tools/android-sdk/`;
если его нет — переиспользуется `C:/Projects/239/tools/android-sdk`,
иначе скачивается при первом запуске. Подпись генерируется в
`tools/keks.keystore` (пароль в `tools/keystore.properties`).

Выход: `dist/keks.apk` (~98K).

## Проверка

```bash
npm test                      # автономность бандла: внешних ссылок нет
./tools/run-emulator.sh       # headless-эмулятор: установка, запуск, скриншоты
```

Эмулятор запускается headless (swiftshader), сеть в нём выключается
перед стартом приложения — проверяется именно офлайн-работа.

## Структура

```
site/                    игра (index.html + style.css + js/*.js)
  js/util.js             математика, RNG, изометрия
  js/audio.js            генеративные SFX + эмбиент (WebAudio)
  js/data.js             дизайн: темы, бестиарий, боссы, скиллы, реплики
  js/dungeon.js          3 генератора уровней, туман войны, поток-филд
  js/sprites.js          процедурные спрайты: тайлы, герои, демонессы, хлыст
  js/entities.js         игрок, ИИ врагов, боссы, снаряды, дропы, частицы
  js/skills.js           дерево навыков
  js/save.js             localStorage-сейвы
  js/ui.js               экраны, HUD, джойстик, лагерь, торговка
  js/main.js             игровой цикл, рендер, свет, состояния
android/
  app/src/main/          манифест, MainActivity (WebView, fullscreen)
  assets/www/            офлайн-бандл (собирается из site/)
tools/
  build-www.sh           site/ → android/assets/www/ + контроль автономности
  build-apk.sh           APK без Gradle: aapt2 → javac → d8 → zip → apksigner
  gen-icons.mjs          иконки (PNG, чистый node + zlib)
  calibrate-xp.mjs       калибровка кривой опыта 1→100 ур ≈ 1000 часов
  run-emulator.sh        прогон в headless-эмуляторе со скриншотами
dist/keks.apk            результат сборки
```

Подход к сборке повторяет проект 239 (WebView-обёртка без Gradle).

## Контент

18+: пошлые двусмысленные диалоги, флиртующие демонессы, комедийная
эротика. Явной обнажённости нет — «древняя цензура» (пиксельная мозаика)
неизменно прикрывает хлыст Праотца и скромность героя. Первый запуск
спрашивает подтверждение возраста (запоминается).

## Обновление игры

Правишь `site/`, затем:

```bash
./tools/build-apk.sh
```
